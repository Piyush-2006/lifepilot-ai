# LifePilot — Personal Productivity Copilot

A responsive browser-based task planner built with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks with High, Medium, or Low priority
- Complete and delete tasks
- Filter all, in-progress, and completed tasks
- Task count, completed count, high-priority count, and progress bar
- Rule-based next-step suggestions
- Responsive desktop/mobile layout
- Browser localStorage persistence

## Run
Open `index.html` in a modern browser, or use VS Code Live Server.

## Honest limitations
This prototype's guidance is rule-based; it does **not** call an AI model. It does not currently integrate Alexa+, Amazon Bedrock, or any other Amazon service. Tasks stay in the current browser and are not synced to a server. Do not claim these integrations unless you implement and test them.

## Stack
HTML5, CSS3, vanilla JavaScript, localStorage.
